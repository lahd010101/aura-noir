# Aura Noir ✨

Plataforma de comercio electrónico moderna, elegante y exclusiva para fragancias y colecciones de autor.

## 🚀 Tecnologías

- **Vite** - Entorno de desarrollo rápido y bundler
- **JavaScript (ES Modules)**
- **HTML5 & CSS3**

## 📦 Instalación

1. Clona el repositorio:
```bash
git clone <URL_DEL_REPOSITORIO>
cd "Aura Noir"
```

2. Instala las dependencias:
```bash
npm install
```

## 🛠️ Scripts disponibles

- `npm run dev`: Inicia el servidor de desarrollo en `http://localhost:5173/`.
- `npm run build`: Compila y empaqueta la aplicación para producción en la carpeta `dist/`.
- `npm run preview`: Previsualiza la versión de producción localmente.

## 📁 Estructura del Proyecto

```
Aura Noir/
├── public/          # Recursos estáticos (imágenes, logos)
├── src/
│   ├── data.js      # Datos del catálogo de productos
│   ├── main.js      # Lógica e interactividad de la aplicación
│   └── style.css    # Estilos globales y temas
├── index.html       # Página principal
├── package.json     # Configuración y dependencias del proyecto
└── vite.config.js   # Configuración de Vite (opcional)
```
